GPS Ionic
Tecnologias y plugins utilizados
Ionic (Angular Stalone Components)
Plataforma Móvil Capacitor
Plugins
`@capacitor/geolocation` (coordenads en tiempo real)
`@capacitor/filesystem` (creacion de archivos .txt)

Requisitos
Hipervinculo GPS
Hipervínculo de ruta
Guardar ubicación en TXT
Guardar ruta en TXT
